## 十、所有配置使用同一套去留规则

1. **ΔN 净成功数优先；持平时看进度、回退情况和实际成本。** LaterFail、覆盖率、追加次数只解释不排名。
2. 三种有效状态：**新默认候选 / 互补候选 / 本轮关闭**。**只有推进、没有整题成功的分支，不能写成已经提升交付精度。**
3. 每一项终态必须区分：`已运行有收益 / 已运行无收益 / 已运行有互补信号 / 与既有配置重复 / 条件未触发 / 依赖阻塞 / 实现失败`。
4. **不按题目 ID 形成最终算法。**
